# Telegram (Telethon) -> n8n -> amoCRM Pipeline

Сервис для автоматического перехвата документов и фотографий из Telegram-аккаунтов и передачи их в n8n для последующего распознавания (Gemini Vision AI), загрузки в облако (Яндекс Диск) и фиксации в amoCRM API v4.

---

## Структура проекта

- **`config.py`** — загрузка конфигурации `.env`, каталогов сессий и параметров аккаунтов.
- **`accounts.json`** — реестр сессий аккаунтов (поддерживает работу с 1 или несколькими аккаунтами одновременно).
- **`sessions/`** — папка хранения бинарных файлов сессий Telegram (`.session`).
- **`auth.py`** — интерактивная утилита для авторизации и добавления аккаунтов.
- **`uploader.py`** — модуль асинхронной передачи файлов и метаданных в n8n через `multipart/form-data`.
- **`main.py`** — основной фоновый сервис (демон), запускающий все активные аккаунты параллельно.
- **`n8n/telegram_pipeline_workflow.json`** — готовый воркфлоу для импорта в n8n (`http://localhost:5678`).

## Быстрый старт: Подключение вашего Telegram-аккаунта

### Шаг 1. Получение API ID и API Hash
1. Перейдите на официальный портал Telegram: **[https://my.telegram.org](https://my.telegram.org)**.
2. Войдите по своему номеру телефона.
3. Перейдите в раздел **API development tools**.
4. Заполните любое имя приложения (например, `DocManager`) и короткое имя.
5. Скопируйте **`App api_id`** (число) и **`App api_hash`** (строка).

### Шаг 2. Настройка `.env`
Откройте файл `.env` в корне проекта и укажите:
```ini
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
N8N_WEBHOOK_URL=http://localhost:5678/webhook/telegram-doc
```
*(Параметры GEMINI, YANDEX и AMOCRM можно оставить пустыми — мы настроим их на следующем этапе).*

---

### Шаг 3. Авторизация аккаунта
В терминале выполните команду:
```bash
python auth.py
```
Скрипт запросит:
1. `API ID` и `API HASH` (если они не были прописаны в `.env`).
2. Имя сессии (по умолчанию `account_1`).
3. Номер телефона в международном формате (например, `+79991234567`).
4. Код подтверждения, пришедший в ваше приложение Telegram.
5. Пароль двухфакторной аутентификации (2FA / Облачный пароль), если он установлен на аккаунте.

После успешного входа файл сессии сохранится в папке `sessions/account_1.session`, а данные аккаунта будут занесены в `accounts.json`.

---

### Шаг 4. Добавление дополнительных аккаунтов (мультисессионность)
Если в будущем потребуется подключить второй, третий и более аккаунтов:
Просто повторно запустите:
```bash
python auth.py
```
Укажите новое имя сессии (например, `account_2`) и номер второго аккаунта. Обе сессии будут работать параллельно в одном процессе.

---

### Шаг 5. Импорт сценария в n8n
1. Откройте локальный n8n: [http://localhost:5678](http://localhost:5678).
2. Нажмите **Add workflow** -> **Import from File...** (или нажмите `Ctrl+V` на холсте) и выберите файл:
   `c:\Users\Lenovo\Documents\Telethon\n8n\telegram_pipeline_workflow.json`.
3. Воркфлоу сразу отобразит цепочку:
   `Webhook` -> `Парсинг` -> `Gemini Vision AI` -> `Яндекс Диск` -> `amoCRM API v4`.
4. Активируйте воркфлоу (переключатель в положение **Active**).

---

### Шаг 6. Запуск сервиса перехвата
Запустите основной скрипт:
```bash
python main.py
```
Скрипт подключится ко всем активным аккаунтам. При отправке клиентом любого фото или документа в личный чат:
- Файл скачивается в память.
- Извлекаются метаданные отправителя (`sender_id`, `phone`, `username`, `first_name`, `last_name`, `caption`).
- Отправляется multipart POST запрос в вебхук n8n.
