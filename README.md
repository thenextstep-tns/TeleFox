# FoxyGram

A from-scratch Telegram client for Android, with an always-on companion server for a
Windows laptop that tracks conversations about the same topic across chats.

Work in progress. See [docs/architecture.md](docs/architecture.md). To run the server on another PC, see
[docs/setup-on-a-new-pc.md](docs/setup-on-a-new-pc.md).
