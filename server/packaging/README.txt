FoxyGram Server

1. Keep this folder somewhere permanent and run install.cmd.
2. A page opens at http://127.0.0.1:8788. Sign in to Telegram there.
3. In a terminal, run: claude auth login
   Analysis goes through your Claude plan and counts toward its weekly limit.
4. Pick the chats to analyse. Nothing is read or stored until you do.

Settings and data: %LOCALAPPDATA%\FoxyGram
To remove it: uninstall.cmd
